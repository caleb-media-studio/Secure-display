Protected document renderer

Public test-key experiment only. To encrypt our synthetic rasterized text into real DRM HLS/DASH, run bun run drm:demo:package with Shaka Packager installed. The content key and licensing token are published by Axinom and provide no confidentiality; this tests rendering and screenshot exclusion only. No canvas or plaintext fallback is used.

No selection.

Selection highlights are geometric overlays. The selected words are not stored in HTML, text nodes or copied to clipboard. Accessibility and native selection semantics remain open limitations.

Run bun run drm:demo:package to generate synthetic text, geometry, and DRM packaged local test media. The script requires FFmpeg, Shaka Packager, and Axinom's publicly available test service. See integration guide.
