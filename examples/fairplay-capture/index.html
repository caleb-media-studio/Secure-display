What to measure

  1. Check diagnostic events for selected EME key system and moving video playback.
  2. Confirm you personally see moving frames on the monitor.
  3. Use Command + Shift + 4 to capture the media, then Command + Shift + 5 to record.
  4. Compare the captured file against what you saw on the physical display. Note OS and browser version.

Cross-origin denial, a license error, or a blank player BEFORE playback does not show DRM screenshot protection.
