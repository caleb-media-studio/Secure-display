How this works / limits

This prototype does not request a browser screenshot-blocking API. It automatically converts the actual HTML snapshot to DRM pixels during the developer build. DOM interactions stay native and no app/extension is required for visitors, but the protected image is static and CSS/DOM changes require a rebuild. Browser, CDM and operating-system capture behavior must still be tested separately.

No plaintext fallback.
