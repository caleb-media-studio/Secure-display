Browser DRM capability check

This checks strict hardware DRM candidates and an informational software Widevine baseline. A software result is never used to display confidential content. Chrome on macOS can reject hardware Widevine while accepting software Widevine. FairPlay should be investigated separately in Safari using actual encrypted HLS playback.
